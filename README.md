SOME ANSWERS OF QUESTIONS-
1/JSX- The full form of JSX is javaScript XML.Primarily used in React to write HTML-like markup directly inside JavaScript files.

2/whats the differnce between props and state?
The main difference between props and state in React boils down to ownership and mutability: props pass data into a component from the outside, while state manages data inside the component locally.

3/what does the usestate hook do and where do u use in this project?
The useState hook is a React function.It allows components to "remember" values that lets you add local state to functional components and updates the user interface automatically whenever those values change.
